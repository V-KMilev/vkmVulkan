# Contributing to vkmVulkan

Thank you for wanting to help. vkmVulkan has no code yet, so the first step is talk: open an
[issue](https://github.com/V-KMilev/vkmVulkan/issues) before writing any, so the shape is agreed
before the work is done.

## Before you write code

Read [vkmOpenGL](https://github.com/V-KMilev/vkmOpenGL)'s README and docs: this library answers
the same needs on Vulkan. vkmEngine's
[CONTRIBUTING.md](https://github.com/V-KMilev/vkmEngine/blob/master/CONTRIBUTING.md) says how the
code looks and what a pull request needs; the same holds here.
